## 🎯 Overview

IntelliFlow Agent is a production-ready autonomous agent that automates end-to-end customer support workflows. The system demonstrates the ability to handle ambiguous inputs, invoke external tools, and incorporate human-in-the-loop checkpoints at critical decision points.

Built entirely with **HTML, CSS, and JavaScript** for maximum portability and ease of demonstration. The frontend simulates integration with Alibaba Cloud services including Qwen AI (DashScope), ECS, RDS, Redis, and OSS.

---

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 🤖 **Multi-Intent Understanding** | Detects multiple intents in a single customer message with confidence scores |
| 📊 **Dynamic Quote Processing** | Real-time quote evaluation with configurable approval thresholds |
| 👤 **Human-in-the-Loop** | Automatic approval gates for high-value transactions, refunds, and new customers |
| ⚠️ **Ambiguity Detection** | Identifies when customer messages contain multiple conflicting requests |
| 🔄 **Workflow Visualization** | Step-by-step visual tracking of inquiry processing |
| 📈 **Escalation System** | Multi-level escalation to managers with full audit log |
| ☁️ **Alibaba Cloud Integration** | Simulated integration with Qwen AI, RDS PostgreSQL, Redis, and OSS |

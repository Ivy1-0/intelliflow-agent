# IntelliFlow Agent - Enterprise Workflow Automation [![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE) [![Alibaba Cloud](https://img.shields.io/badge/Deployed%20on-Alibaba%20Cloud-orange)](https://www.alibabacloud.com) ## 🏆 Hackathon Track **Track 2: Enterprise Workflow Automation** ## 🎯 Overview IntelliFlow Agent automates customer support workflows with human-in-the-loop checkpoints. Built with HTML/CSS/JavaScript frontend, powered by Alibaba Cloud Qwen AI. ## 🚀 How to Run 1. Open `index.html` in any browser 2. The app runs entirely in the browser 3. No installation required ## 📁 Files - `index.html` - Main application - `style.css` - Styling - `script.js` - Application logic with workflow engine - `alibaba-cloud-proof/deployment.html` - Deployment verification ## 🔍 Features Demonstrated - **Ambiguous Input Handling**: Detects multiple intents in one message - **Human-in-the-Loop**: Approval gates for high-value transactions - **External Tool Simulation**: CRM lookup, email notifications - **Qwen AI Integration**: Intent classification with confidence scores ## 🎥 Demo Video [YouTube Demo Link] ## 📄 License Apache 2.0
